# yubo_website_clone

Yubo is all about chilling. Meet like-minded people or find a group to hang with, then kick back and feel your vibeeee. This clone captures that laid-back spirit by offering a visually engaging, static experience that invites users to explore and connect in a relaxed environment.

Built entirely with HTML and CSS, this project focuses on delivering a clean, intuitive user interface that echoes the chill vibe of the original Yubo. Without the need for backend functionalities, the emphasis is on design, layout, and responsive styling that make the user experience smooth and enjoyable.

Enjoy exploring the design, and feel free to use or modify the code to create your own vibe. Happy chilling!
